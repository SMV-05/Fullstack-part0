sequenceDiagram
    participant browser
    participant server

    Note right of browser: El usuario escribe texto en el campo y hace clic en el botón Save

    Note right of browser: El evento submit es interceptado por JavaScript, que impide la recarga de la página (event.preventDefault())

    browser->>server: POST https://studies.cs.helsinki.fi/exampleapp/new_note_spa
    Note right of browser: El cuerpo de la petición contiene la nueva nota en formato JSON: { content: "...", date: "..." }
    activate server
    server-->>browser: HTTP 201 Created (JSON con la nota guardada)
    deactivate server

    Note right of browser: JavaScript añade la nueva nota al array de notas en memoria y vuelve a renderizar la lista de notas en el DOM, sin recargar la página
